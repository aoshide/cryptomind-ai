# CryptoMind AI — интеллектуальный анализ крипторынка

**Выполнил:** &lt;Баргыбаев Нуртилек&gt;, группа &lt;32&gt;
**Дисциплина:** Машинное обучение (практические работы ПР-1 – ПР-7)

## О проекте

Учебный ML-проект по анализу крипторынка: дневные свечи (OHLCV) BTC/USDT,
ETH/USDT, SOL/USDT за 2017–2026 гг. — задачи регрессии доходности,
классификации рыночных крахов при сильном дисбалансе классов, интерпретации
моделей (SHAP). Отдельная ветка — классификация тем русскоязычных новостей
(компонент анализа информационного фона рынка).

## Структура репозитория


cryptomind-ai/
├── data/
│   ├── raw/            # сырые свечи с Binance (полная история)
│   └── processed/      # собранный датасет crypto_daily.csv + корпус новостей
├── notebooks/          # ноутбуки ПР-1 … ПР-7
├── src/
│   ├── features.py     # CryptoFeatures — пользовательский трансформер (ПР-3)
│   ├── prepare_data.py # загрузка истории с Binance + сборка датасета
│   └── fetch_corpus.py # корпус новостей Lenta.ru через HuggingFace (ПР-6)
├── tests/              # pytest-тесты трансформера (ПР-3)
├── reports/, figures/  # отчёты и графики
├── requirements.txt    # зафиксированные версии библиотек
└── README.md



## Установка и запуск

```bash
git clone <ссылка-на-репозиторий>
cd cryptomind-ai
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # Windows PowerShell
pip install -r requirements.txt

python src/prepare_data.py          # скачает ~9 тыс. дневных свечей с Binance
python src/fetch_corpus.py          # соберёт 600 новостей (ПР-6)

Ноутбуки открыть в VS Code (расширения Python + Jupyter) или Jupyter;
ядро — окружение .venv. Запуск: Restart Kernel & Run All.
Источники данных
Binance Public API (klines, интервал 1d) — BTC/USDT, ETH/USDT, SOL/USDT,
17.08.2017 – 13.10.2026, 8945 строк. Загрузка и сборка воспроизводимы:
python src/prepare_data.py.
Lenta.ru через HuggingFace (zloelias/lenta-ru), стриминг — 600 новостей,
4 темы, разметка редакционная.
Результаты практических работ

| Работа | Содержание                     | Ключевой результат                                                                                                                                  |
| ------ | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| ПР-1   | Окружение, первичный анализ    | Структура проекта, data dictionary, воспроизводимая загрузка                                                                                        |
| ПР-2   | EDA, 3 гипотезы с тестами      | H1: средняя доходность BTC = 0 (p=0.146); H2: корреляция BTC–ETH r=0.815; H3: эффекта дня недели нет (p=0.165). Разобраны 4 источника утечки данных |
| ПР-3   | Пайплайн + свой трансформер    | `CryptoFeatures` (BaseEstimator + TransformerMixin), 3 pytest-теста, ~100k строк обрабатывается < 1 с                                               |
| ПР-4   | Свой градиентный спуск (NumPy) | Коэффициенты совпали со sklearn до 4 знаков; R² ≈ −0.009 у обоих — доходность близка к случайному блужданию                                         |
| ПР-5   | Классификация, дисбаланс 1:16  | Балансировка удвоила F1: 0.052 (baseline) → 0.127 (undersampling); эффект устойчив на 3 разбиениях                                                  |
| ПР-6   | Классификация русских текстов  | TF-IDF + LogReg: macro F1 = 0.941 (Bayes 0.925); главная путаница — «Наука» ↔ «Экономика» (корпоративная лексика)                                   |
| ПР-7   | Random Forest, интерпретация   | Расхождения impurity vs permutation vs SHAP объяснены корреляцией признаков; ловкий скошенный признак (vol\_ratio) завышен impurity-методом         |
